# Обновления Lumen

Начиная с 0.4.8 установленный браузер проверяет `lumen-update.json` в последнем релизе `L4NOTTE/Lumen`. Подходящая версия загружается в фоне и применяется при закрытии окна, если загрузки браузера завершены. Для Windows используется установщик Inno Setup. Для Linux заменяется пользовательский бинарник `~/.local/bin/lumen`. Для системного `.deb` используется менеджер пакетов. На Linux для проверки обновлений нужен `/usr/bin/curl`.

Манифест проверяется встроенным ключом Ed25519. Он содержит версию, срок действия, размер и SHA-256 каждого артефакта. Браузер проверяет файл повторно перед применением. Подпись манифеста авторизует обновление внутри Lumen. Authenticode для доверия Windows настраивается отдельно по SIGNING.md.
